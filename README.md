# web-home

Landing page for croicu.com

---

## Install

```bash
npm install
```

## Develop

```bash
npm run dev       # Vite dev server
```

## Typecheck

```bash
npm run typecheck
```

## Test

```bash
npm test          # Vitest watch mode
npm run test:run  # Vitest single run (CI)
```

## Build

```bash
npm run build      # tsc + vite build -> dist/
npm run preview    # preview dist/ locally
```
